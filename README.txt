MUEBLERÍA GARAY — WEB DEL CATÁLOGO
===================================
Archivos: index.html, styles.css, script.js, products.json y carpeta assets.

IMPORTANTE: Por seguridad del navegador, la página debe ejecutarse desde un servidor local para cargar products.json.

OPCIÓN FÁCIL: Abre la carpeta en Visual Studio Code, instala Live Server, clic derecho sobre index.html > Open with Live Server.
OPCIÓN PYTHON: Desde esta carpeta ejecuta: python -m http.server 8000
Luego visita: http://localhost:8000

PUBLICAR GRATIS: Sube todos los archivos y la carpeta assets a GitHub Pages, Netlify o cualquier alojamiento estático. No necesita servidor backend.
